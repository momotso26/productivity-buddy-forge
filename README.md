# AI Workplace Companion

Build a modern responsive web application called “AI Workplace Productivity Assistant” as a polished, fully functional local-state prototype. Implement the specified fixed sidebar SaaS dashboard and five interactive pages: Smart Email Generator, Meeting Notes Summarizer, AI Task Planner, AI Research Assistant, and Chatbot. Use React, Tailwind, shadcn components, Framer Motion, realistic simulated AI responses with loading/success/toasts, and a premium Notion/Linear-inspired visual style. No API keys or backend required.
